## Representation, best first
1. Typed records: semantic labels; `.byte/.short/.long` with symbolic pointers (`.long Rec - Base`); one macro
   per record type with named parameters; strings as `.ascii`; counts in decimal, masks/flags in hex,
   lowercase hex.
2. A committed generator from committed human-readable source (YAML/JSON/MIDI/text) that reproduces the bytes
   exactly; mark the include `census: generated -- <tool>` (comment on the line or the line above).
3. A standard media file (jpg/bmp/png/wav/mid) when that is what the bytes are.
4. Declared opaque: `census: opaque -- <kind>: <why>` with kind in pcm / compressed / code / unknown-dump /
   personal / fill. PCM sample bodies, entropy-coded streams with no encoder, and blobs you genuinely could not
   decode (say what you tried) qualify. "I ran out of time" is not a reason: leave it generic and list it.
   Every opaque payload is still labelled per item with a comment saying what it is.
Bulk payloads are an `.incbin "ref", skip, count` (llvm-mc) or `.incbin_range "ref", start, end` (kn7asm) of the
git-ignored reference image, never a committed copy.

## Done means
- The image(s) rebuild byte-identical to the reference (SHA-1 checked), with a gate target wired into the
  model's gate (KN5000: `make gate`; kn7000: `gate-kn7000` list; new trees: their own target added to
  `make gate-all` / `make everything`). Reference images git-ignored, copied/regenerated by `make` with a SHA-1
  check, like `KN5000_V8_REF` / kn7000's baserom.
- Your tree has a row in `TREES` of `data_incbin_census.py` (add it if missing) and shows generic = 0, or every
  remaining generic entry is listed in your report with why.
- Every field meaning cites evidence: the firmware routine that reads it (address + label) or a committed probe
  that measured it. Probes go in a `*-probes/` dir beside your notes, with a README saying per script what
  question it answers and how to run it. Mark inferences as inferences.
- A notes README for your lane (format documentation, evidence, open questions, Website page draft).
- Do not write census snapshots (`--snapshot`) or semantic-score/badge files: the integrator does that after
  merging. You may run them read-only.

  assert_byte_identical.py, .gitignore): other lanes edit them too. Keep your edits there small and
  self-contained (one block / one row) so merges are easy.
