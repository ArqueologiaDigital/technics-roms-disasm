## Idioms found today

- A frame-address argument that the ROM computes into its register BEFORE the stack pushes comes from a variable
  assigned just before the call (`s = buf;`, `pw = &w;`, pointer locals): DrawStringCentered / RightJustify / Reverse,
  the DSPCfg multi-field pair, FDC_ExecuteSectorCommand, TtlScreenProc.
- `(unsigned int)(a == b)` for a comparison widened with extz (VwBoxProc).
- A compare chain is a `switch`; V4.23 compares the case labels in reverse source order; a default the ROM places right
  after the compares is written first (SetWallColor).
- Declaration order decides XIX / IX / IY; one variable for two uses keeps one register (CalcTotalWidth,
  SeqVoice_ComputeStatusFlags).
- A 7-byte member array inside a struct is padded to 8 by V4.23 (the MidiPkt record family).
- `v >>= s` already gets V4.23's own `and a,15; jr z`.
- A call that ends an `if` without `else` stays call + ret; an if / else gives tail jumps at both ends; a call at the
  end of the function becomes a tail jump (helper N's rule, held across the MIDI bulk-dump family).
- V4.23 homes a byte flag in QIZ like the ROM; a parameter id is the address of a byte in a null-based struct row
  (row pointer, then the offset) — the key to the sound-editor table handlers of modules 128 / 129 / 152.
- Operand order of a compare: `cp (mem),r` comes from `mem != reg_expr` written with the cell on the left
  (FDemoText_UpdateVoiceDisplay).

## Lessons for the pipeline

- `restage_modules.py`, `port_staged.py` and `staged_v423.py --record` rewrite and re-check every staged file: a note in
  a staged file does not hold it back; a function that cannot be spliced must leave the staging.
- When `promote_staged.py` stops at a failed splice: restore the half-written C file (`git checkout --` / one `rm`),
  `git rm` what `list_promoted.py` lists, drop the failing function's staging, run it again.
- `git commit -F MSG -- PATHS` keeps a probe-file commit from sweeping up `git rm`s already in the index.
