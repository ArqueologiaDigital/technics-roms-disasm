## Idioms found today

- A frame-address argument (`lda xde,(xsp+N)`) that the ROM computes BEFORE the stack pushes comes from a variable
  assigned just before the call: `s = buf; DrawString(r, &at, s, ...)` (DrawStringCentered / RightJustify),
  `pw = &w;` (DSPCfg_ReadMultiField / WriteMultiField), pointer locals (DrawStringReverse's plain branch,
  FDC_ExecuteSectorCommand).
- A comparison the ROM widens with `extz` is `(unsigned int)(a == b)` (VwBoxProc).
- A compare chain is a `switch`: V4.23 compares the case labels in reverse source order.
- The declaration order of register locals decides which gets XIX / IX / IY (CalcTotalWidth matched with the glyph
  pointer declared before the index); one variable used for two values keeps one register.
- V4.23 pads a 7-byte member array inside a struct to 8 bytes (helper M; the MidiPkt record family matched once the
  fields sat at the ROM's offsets).
- `v >>= s` already carries V4.23's own `and a,15; jr z`: do not write `& 15` (helper M).
- `asm_vs_rom.py` strips leading `_` and `.` from listing names, so a C call to `_Write_VGA_Register` resolved to
  `Write_VGA_Register`; name such labels through `cc900-name:` aliases (helper L).
