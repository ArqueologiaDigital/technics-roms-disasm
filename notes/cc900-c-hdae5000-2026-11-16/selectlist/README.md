# SelectListProc: the read-out of run 2026-11-17-15-hd-r44 and round 46's probe

Written by lane_hd's helper h_n2 (2026-11-17).  `HDAE5000_SelectListProc` (2,641 B) is the largest v2.06i function
still without matching C.  These files decided two things that lane_hd reported: that the index's "difference at
+23" is only an unresolved branch distance (the frame and every stack offset already match), and the five forms of
`probes/hd_r46_n2.c`.  Run every command from the worktree root.

- **`cmp.py`**: where does V4.23's code for one C form differ from the ROM's SelectListProc, instruction by
  instruction, ignoring branch distances, jr / jrl and call / calr lengths?
  `python3 -B notes/cc900-c-hdae5000-2026-11-16/selectlist/cmp.py SHOW OUTDIR TAG`
- **`gen.py`**: writes `probes/hd_r46_n2.c`, the label's form and four variants that differ only in the two
  unsettled items.
  `python3 -B notes/cc900-c-hdae5000-2026-11-16/selectlist/gen.py notes/cc900-c-hdae5000-2026-11-16/probes/hd_r46_n2.c`
  `gen.py --round 50|52|55|57 OUT` writes round 50's, 52's, 55's or 57's probe (`probes/hd_r5N_sl.c`, 2026-11-18;
  each round's header says what the run before it showed).  `cmp.py ... TAG LABEL [SIZE]` compares any other
  v2.06i function (SIZE: a procedure the survey split into pieces).
- **`head.txt`**, **`body.tpl`**: `gen.py`'s inputs.  `head.txt` holds the probe's header comment (the read-out
  table) and declarations; `body.tpl` holds the function body, with `@NAME@`-style slots for what the forms change.

`cmp.py`:
- `SHOW` is the output of `hd_v423.py --show RUN CNAME` for one C form, saved under `$TMPDIR` (it holds Toshiba
  listing text, so it is never committed).  `cmp.py` takes the generated bytes from it, writes them to
  `OUTDIR/gen_TAG.bin`, and prints a unified diff between the two disassemblies, ROM first.
- Both sides go through MAME's `unidasm` (`../../tools/unidasm` from a worktree under `disasm-lanes/`).  Branches
  print as `BR cc`, calls as `CALL`, so only real differences remain.
- The ROM side is fixed to SelectListProc: offset 0x7d9 of `original_ROMs/hd-ae5000_v2_06i.ic4`, 2,641 bytes.

Checked when committed: `gen.py` rewrites `probes/hd_r46_n2.c` byte for byte.  `cmp.py` on run 15's label form
reports 806 ROM instructions against 795 generated, with the differences in items 3 and 4 of the read-out table.
