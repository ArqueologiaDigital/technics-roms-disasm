## What 2026-11-19 learned (README has the details)

- **The firmware's inline assembly is the lower-case `__asm("...")`.**  V4.23 treats it as clobbering the scratch
  registers, so values live across it go to the XIZ family (XIZ, IZ, QIZH, QIZL, IZH), pushed, as in the ROM;
  `__ASM` does not.  This alone matched 27 tone-generator writers stuck at +0 since round 3, then 15 more.  `__IZ` /
  `__XIZ` (bug candidate 12) are not needed for them.  `#pragma asm` is unknown to V4.23.
- **8-bit narrowing:** `uchar + K` / `uchar * K` (K < 256) are byte operations; the ROM's `extz wa; add / muls` need
  `(int)x + K` / `(int)x * K`.  A constant added to an int index of a LOCAL array is folded into the frame address
  (Voice_SetVelocity: no spelling found; parked).
- **Unary plus stops folding of a sum** (`+(x * K + 0x10) + ptr`); an `unsigned long` global added last is a memory
  operand (DSP_Reinit_VoiceSlots).  `(unsigned int)(int)(i * 56 + 8)` keeps a +8 out of a base address
  (DSP_EFFParam_DiffAllAndFlag).
- **Record fields through a struct cast on the record's byte address** give `lda xbc,(xbc+wa)` (Voice_Reset_Engine);
  a pointer then an offset in a second statement (`s = ...; s += (unsigned int)k;`) keeps the ROM's order
  (Voice_ParamFinalize).
- **Pool rows can hold several functions**: the 1,389-byte "Voice_Level_ComputeTriplet" was five (span_refs.py);
  Voice_ParamFinalize is one function over 33 labels with two case tables.
- **Odd-size record copies stay blocked**: memcpy is a library call in V4.23; `#pragma pack` is ignored.
- **Translator gaps closed** (`model/to_llvm.py`): an extended byte register as the second operand (`cp L,QC` ->
  `cpb_erp`; `erp_operand_check.py`), and asm900's `fims()` (`fims_check.py`).  `._fneg_f` = FP_SP_CopyOrNegate4 is
  a row of `scripts/build/cc900_runtime_names.tsv` (confirmed by DSP_DetuneCurve_SignedFP).
