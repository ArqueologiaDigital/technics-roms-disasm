0x28b2 SEQ_METRO_FLAGS ; the record pages' metronome and its count-in (per bit: notes/kn5000-naka3-2026-11-07/probes/flag_bit_ops.py 0x28b2).  bit 0 = the METRONOME switch of TT_SQREALREC / SQCYCREC / SQPUNCH / SQPUNCHM is on: MetroOnOffFunc posts EVT_SET_METRO (MT_SetMetro) to ApPlaySyori, whose ApPlaySyori_OnSetMetro sets or clears it (only while neither the sequencer runs nor bit 2 is set; on TT_SQREALREC switching it on opens TT_SQMETBAL), and the four record screens show it (EVT_SET_PARAM to 0x87000d / 0x880004 ...); with it the punch-in start becomes measure -2 (0x8002, SeqPlay_UpdateStartFromPunchIn), and a key does not end record standby (AccAutoPlay_NoteDispatch_Process, AccAutoPlay_SplitDetect): the count-in does; bit 1 = this take starts with the metronome count-in: set with bit 0 when recording starts (SeqPlay_InitTempoAndActivateParts, SeqPlay_InitFresh_PartLoopNext, SeqPlay_InitResume_LoopNext, which also save SEQ_START_MEASURE in 0x2336 for SeqPlay_SaveState_NoActiveParts to restore); a start request then arms the count-in instead of starting (AccPlayMode_StopExprB / AccPlayMode_StartPlayFull), SeqPlay_CheckAndStartPlayback ignores start requests, and SeqPlay_CountInEnd ends record standby (SEQ_CONTROL_FLAGS bit 3) on the last beat of measure -1; bit 2 = the count-in runs: set by AccPlayMode_StopExprB / AccPlayMode_StartPlayFull with the start measure at -2 (SeqPlay_SetBarAndResetScroll), SeqPlay_CountInToLastBar then moves -2 to -1; bits 1, 2 and 7 are cleared by SeqPlay_ResetPlaybackState, SeqPlay_FinalCleanup_ClearFlags, SeqPlay_InitFreshPlayback and SeqPlay_InitResumePlayback (bits 1, 2 also by AccWrap_PlayModeStateMachine_Skip and CDlikeTimer_ResetAccompaniment); no code sets bit 7; bits 3-6 are untouched; AudioMode_CopyChannelMode copies bits 0-1 to 0x3335
0x28b3 SEQ_CONTROL_FLAGS ; requests and states of the sequencer's start / stop paths (per bit: notes/kn5000-naka3-2026-11-07/probes/flag_bit_ops.py 0x28b3).  bit 0 = a screen redraw is due: SeqNotify_DataBlock sets it, SeqNotify_CheckAndClearStart runs BitMapOut_ComputeRegionDelta (not on TT_SQPUNCH / SQPUNCHM) and clears it; bit 1 = recording was started by a start request in record standby (SeqPlay_CheckAndStartPlayback sets it); SeqPlay_SaveAndPrepareState and its arms test and clear it when the sequencer stops; bit 2 = a restart check is due after a stop: SeqPlay_StopReset_CleanupAll sets it (with bit 4), SeqPlay_HandleVoiceReassign runs SeqRestart_CheckAndDispatch unless PANEL_STYLE+5 & 0x30, then clears it and sets bit 4; Seq_ResetAndRestartAccompaniment clears it; bit 3 = record standby: record tracks are armed but recording has not begun: set when playback starts with SEQ_REC_TRACKS non-empty (SeqPlay_InitTempoAndActivateParts, SeqPlay_InitFresh_*, SeqPlay_InitResume_SetFlags), cleared when the count-in ends (SeqPlay_CountInEnd), by the first synchro-start key (AccAutoPlay_NoteDispatch_Process) and by the stop paths (SeqPlay_FinalCleanup_ClearFlags, SeqPlay_SaveState_*, SeqPlay_StopAndCleanup, SeqPlay_ReactivatePartsAndResume); while it is set Audio_CheckInitStatus clears AUDIO_SEQ_TRACK_FLAGS bit 9 (AudioInit_SetChangedFlag) and AccAutoPlay_SplitDetect skips the split check; bit 4 = the sequencer's buffers are to be re-initialised once it is idle: set by 15 instructions (the stop paths, SeqPlay_InitStartState, SeqTimer_BarChangeProcess, PlayMode_TeardownAndRestore, the step editor), SeqPlay_InitBuffers runs SeqPlay_AllocBuffersAndInit when neither sequencer nor accompaniment runs and clears it, SeqPlay_ResetStartState clears it; bit 5 is tested by SeqNote_NoteOn_HasParts, AccPedalCfg_CheckBit6Replay, NotePool_DataBlock_890 and SeqPlay_CheckStart_TestBit5 and cleared by seven routines, but no code sets it; bit 6 is set by Banner_Loop_CheckEntry, SqStep_AuditionCursorNotes, SoundEvt_Mode1_StepAndRefresh_Helper and VoiceCtrl_SendNoteOffSequence and read by nothing; bit 7 is untouched
