# Probes of lane kn5000-style (2026-10-31)

Every script is read-only and takes the repository (or an extracted floppy directory) as an argument.

| script                  | question it answers                                                                                                                      | command                                                                                                                                                      |
|-------------------------|------------------------------------------------------------------------------------------------------------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `style_bank_readers.py` | Which v10 instructions touch the Composer style image's header, section records and the area after the directory? (ABS / IMG / REC rows) | `python3 style_bank_readers.py [REPO] [--window N] [--off LO HI]`                                                                                            |
| `sqt_field_refs.py`     | Who reads or writes each field of the current-song record (SEQ_SONG_RECORD, the .SQT slot), in v5..v10, in four spellings?               | `python3 sqt_field_refs.py [REPO] [--trees v10,v9] [--field NAME ...] [--summary]`                                                                           |
| `tm_subcpu_refs.py`     | Which sub-CPU v1.42 instructions read a tone-record byte, through the record or partial-block pointer?                                   | `python3 tm_subcpu_refs.py [REPO] [--rec OFF ...] [--blk OFF ...]`                                                                                           |
| `panel_sndparam_map.py` | Which panel parameter does each byte of a panel record hold, by the firmware's SndParam descriptors?                                     | `python3 panel_sndparam_map.py [REPO] [--tag 0xTT ...] [--json OUT]`                                                                                         |
| `panel_field_refs.py`   | Which maincpu instructions name a panel record byte directly (writes `specs/panel_field_refs.json`)?                                     | `python3 panel_field_refs.py [REPO] --json notes/floppy-kn5000-2026-10-29/specs/panel_field_refs.json`                                                       |
| `dsp_slot_params.py`    | Which DSP parameter is each byte of a DSP slot record, and do the saved values fit (writes `specs/dsp_effect_params.json`)?              | `python3 dsp_slot_params.py original_ROMs/kn5000_v10_program.rom --json notes/floppy-kn5000-2026-10-29/specs/dsp_effect_params.json --check <extracted dir>` |
| `style_links.py`        | Where are the non-mutual cell links and the undecodable chains, and can the firmware reach them?                                         | `python3 style_links.py <extracted dir>`                                                                                                                     |

`<extracted dir>`: `for d in floppy/kn5000/baserom/*.img; do python3 floppy/tools/fat12_extract.py $d $TMPDIR/ext/$(basename $d .img); done`.
