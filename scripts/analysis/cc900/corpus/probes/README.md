# Hand-written probe corpora

Probe files that `gen_micro.py` does not generate. Each one is our own C89, written for a research-scratch fit and
copied here so the ledger (`model/ledger.sh`) can score the model against its oracle run.

| file         | question it answers                                                                                                                                                                                                                                                                   | oracle run                            | fit (research-scratch)                                                                              |
|--------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|---------------------------------------|-----------------------------------------------------------------------------------------------------|
| `fpp1.c`     | where V4.23 puts double temporaries when calls, arguments and operations compete for frame slots (E2); which free op slot it reuses (E3)                                                                                                                                              | `2026-11-09-18-micro-fpprepass`       | `sessions/2026-11-09_cc900-fp-prepass`                                                              |
| `fpp2.c`     | the same, second round (statement order, parity, long temporaries)                                                                                                                                                                                                                    | `2026-11-09-19-micro-fpprepass2`      | `sessions/2026-11-09_cc900-fp-prepass`                                                              |
| `fpp3.c`     | E2: which statements move the slots of others (call-only, operation-only and mixed families; the kinds of statement that count)                                                                                                                                                       | `2026-11-09-26-micro-fpe2`            | `sessions/2026-11-09_cc900-fp-e2`                                                                   |
| `fpp4.c`     | E2: where one operation slot lies among n call slots (generated by the session's `gen_fpp4.py`)                                                                                                                                                                                       | `2026-11-09-28-micro-fpe2b`           | `sessions/2026-11-09_cc900-fp-e2`                                                                   |

| `evorder_d.c` | the int kinds for / and % (`ed_*`): the same order rule with the accumulator in WA (`exts XWA / divs XWA,src / ld HL,WA`, the remainder from QWA; -O with a plain left: `divs XHL`), the source in BC (`gen_evorder3.py`, run 2026-11-10-11-micro-evorder3) |
| `cmpord.c`    | the int kinds on both sides of `<` and `==` as an `if` condition (`ci_l_*`, `ci_e_*`) and of `<` as a value (`cv_l_*`): the same order rule as the operators, the compare instruction's operands per kind pair (a memory left stays in memory against a computed right: `cp (_gi),WA` for `<`, `cp WA,(_gi)` for `==`; a shift's value in BC) (`gen_cmpord.py`, run 2026-11-10-12-micro-cmpord) |
| `evorder_lh.c` | the long kinds on both sides of `*`, `/`, `%` (`eh_*`), which call `C9H_mulls` / `divls` / `remls`: the left argument in XWA and the right in XBC (`*` puts the operator rule's accumulator in XWA), pointer addresses first, the source value, the accumulator value, plain loads (a plain variable before a member), constants last, pointer loads last in place (`gen_evorder_lh.py`, run 2026-11-10-13-micro-evorder4) |
| `loc0.c`     | where V4.23 keeps a local with an initialiser (`lo_<type>_<init><mid><use>`, 512 functions): WA when nothing but its own uses follows, else the lowest of BC, DE, HL that the code in between does not write, IZ / QIZ / XIZ across a call (homes2), HL / L / XHL for a call result; the model's rule is `plan_regtemps` (run 2026-11-10-14) |
| `stord.c`    | the order and the registers of a store's address and value (`st_<i|l|c>_<lvalue><value>`, 432 functions): the address first in XBC before a loaded value in WA, in XWA before an arithmetic value in BC for a member through a pointer, after a call, after a divide by an indexed element (run 2026-11-10-15; the model's rule is `store_plan`)       |
| `cmpordl.c`  | the operands of long and char compares (`cl_<l|e>_<L><R>` over 14 long kinds, `cc_<l|e>_<L><R>` over 12 char kinds, 680 functions): which side loads, which register it takes, the `==` forms that load the right side, the ?: arms, a call's result in XHL / L, char operands compared at the byte (run 2026-11-10-16; the model's rule is `cmp_wide`) |
| `evorder_ad.c` | the order of evaluation of a binary operation with addressed operands (`ea_<i|l|c>_<op>_<L><R>`: a deref, a member through a pointer, an element at c, a constant element, a call; + - & | ^ * / %; 1,116 functions): the right's address first, a left pointer's own load before it, the commutative swap that loads the right of two addressed sides, a call as the accumulator (run 2026-11-10-17; the model's rule is `bin_wide`) |
| `cmpordl2.c`  | compare operands of the second wave (`c<i|l|c>_<l|e>_<L><R>`, 572 functions): a pointer at a constant index, a member array through a pointer, an element at a local index, widening and narrowing casts, an element shifted by a constant, a call with an argument, a masked deref (run 2026-11-10-18) |
