# Hand-written probe corpora

Probe files that `gen_micro.py` does not generate. Each one is our own C89, written for a research-scratch fit and
copied here so the ledger (`model/ledger.sh`) can score the model against its oracle run.

| file         | question it answers                                                                                                                                                                                                                                                                   | oracle run                       | fit (research-scratch)                                                                              |
|--------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|----------------------------------|-----------------------------------------------------------------------------------------------------|
| `fpp1.c`     | where V4.23 puts double temporaries when calls, arguments and operations compete for frame slots (E2); which free op slot it reuses (E3)                                                                                                                                              | `2026-11-09-18-micro-fpprepass`  | `sessions/2026-11-09_cc900-fp-prepass`                                                              |
| `fpp2.c`     | the same, second round (statement order, parity, long temporaries)                                                                                                                                                                                                                    | `2026-11-09-19-micro-fpprepass2` | `sessions/2026-11-09_cc900-fp-prepass`                                                              |
| `fpp3.c`     | E2: which statements move the slots of others (call-only, operation-only and mixed families; the kinds of statement that count)                                                                                                                                                       | `2026-11-09-26-micro-fpe2`       | `sessions/2026-11-09_cc900-fp-e2`                                                                   |
| `fpp4.c`     | E2: where one operation slot lies among n call slots (generated by the session's `gen_fpp4.py`)                                                                                                                                                                                       | `2026-11-09-28-micro-fpe2b`      | `sessions/2026-11-09_cc900-fp-e2`                                                                   |
| `adfp.c`     | where float and double parameters and arguments go under each convention, and whether one uses up an adecl register position                                                                                                                                                          | `2026-11-09-29-micro-adfp`       | none (read directly: a double is on the stack and uses up its position; a float is in its register) |
| `chnarrow.c` | when int arithmetic on a char is done in the byte and extended afterwards (constants that fit a byte, two chars, the four operators, ?: with char arms)                                                                                                                               | `2026-11-09-30-micro-chnarrow`   | none (read directly; the rule is `codegen.char_narrow`)                                             |
| `lnr.c`      | leaf functions without options: which registers a loop body keeps from variables live across it (three dummy locals fill the free registers before the counter), parameter against local order, use count against declaration order, which variable a return expression pulls into HL | `2026-11-09-31-micro-lnr`        | `sessions/2026-11-09_cc900-leaf-none`                                                               |
| `lnr2.c`     | the same loop bodies with the counter allocated first; which first reference makes a parameter be allocated before the locals                                                                                                                                                         | `2026-11-09-32-micro-lnr2`       | `sessions/2026-11-09_cc900-leaf-none`                                                               |
| `lnr3.c`     | when a held lvalue address (`p[i] += q[i]`) keeps BC from the counter (alone, not with another variable live across); more first references of parameters                                                                                                                             | `2026-11-09-33-micro-lnr3`       | `sessions/2026-11-09_cc900-leaf-none`                                                               |
| `lnr4.c`     | held-out check of the fitted rule LN1 (predictions recorded before the run); every local starts from a distinct constant                                                                                                                                                              | `2026-11-09-34-micro-lnr4`       | `sessions/2026-11-09_cc900-leaf-none`                                                               |

Score one with (from `scripts/analysis/cc900`; the listing directory and `--opt` are given explicitly):

    python3 -I -B model/score.py ~/compartilhado/cc900-oracle/runs/2026-11-09-18-micro-fpprepass/out/v423/O3XS/micro corpus/probes/fpp1.c --opt O3XS

An `-Xr` listing also needs `--adecl` (the directory name no longer ends in `Xr`):

    python3 -I -B model/score.py ~/compartilhado/cc900-oracle/runs/2026-11-09-29-micro-adfp/out/v423/Xr/probes corpus/probes/adfp.c --opt none --adecl
