# Hand-written probe corpora

Probe files that `gen_micro.py` does not generate. Each one is our own C89, written for a research-scratch fit and
copied here so the ledger (`model/ledger.sh`) can score the model against its oracle run.

| file         | question it answers                                                                                                                                                                                                                                                                   | oracle run                            | fit (research-scratch)                                                                              |
|--------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|---------------------------------------|-----------------------------------------------------------------------------------------------------|
| `fpp1.c`     | where V4.23 puts double temporaries when calls, arguments and operations compete for frame slots (E2); which free op slot it reuses (E3)                                                                                                                                              | `2026-11-09-18-micro-fpprepass`       | `sessions/2026-11-09_cc900-fp-prepass`                                                              |
| `fpp2.c`     | the same, second round (statement order, parity, long temporaries)                                                                                                                                                                                                                    | `2026-11-09-19-micro-fpprepass2`      | `sessions/2026-11-09_cc900-fp-prepass`                                                              |
| `fpp3.c`     | E2: which statements move the slots of others (call-only, operation-only and mixed families; the kinds of statement that count)                                                                                                                                                       | `2026-11-09-26-micro-fpe2`            | `sessions/2026-11-09_cc900-fp-e2`                                                                   |
| `fpp4.c`     | E2: where one operation slot lies among n call slots (generated by the session's `gen_fpp4.py`)                                                                                                                                                                                       | `2026-11-09-28-micro-fpe2b`           | `sessions/2026-11-09_cc900-fp-e2`                                                                   |
| `adfp.c`     | where float and double parameters and arguments go under each convention, and whether one uses up an adecl register position                                                                                                                                                          | `2026-11-09-29-micro-adfp`            | none (read directly: a double is on the stack and uses up its position; a float is in its register) |
| `chnarrow.c` | when int arithmetic on a char is done in the byte and extended afterwards (constants that fit a byte, two chars, the four operators, ?: with char arms)                                                                                                                               | `2026-11-09-30-micro-chnarrow`        | none (read directly; the rule is `codegen.char_narrow`)                                             |
| `lnr.c`      | leaf functions without options: which registers a loop body keeps from variables live across it (three dummy locals fill the free registers before the counter), parameter against local order, use count against declaration order, which variable a return expression pulls into HL | `2026-11-09-31-micro-lnr`             | `sessions/2026-11-09_cc900-leaf-none`                                                               |
| `lnr2.c`     | the same loop bodies with the counter allocated first; which first reference makes a parameter be allocated before the locals                                                                                                                                                         | `2026-11-09-32-micro-lnr2`            | `sessions/2026-11-09_cc900-leaf-none`                                                               |
| `lnr3.c`     | when a held lvalue address (`p[i] += q[i]`) keeps BC from the counter (alone, not with another variable live across); more first references of parameters                                                                                                                             | `2026-11-09-33-micro-lnr3`            | `sessions/2026-11-09_cc900-leaf-none`                                                               |
| `lnr4.c`     | held-out check of the fitted rule LN1 (predictions recorded before the run); every local starts from a distinct constant                                                                                                                                                              | `2026-11-09-34-micro-lnr4`            | `sessions/2026-11-09_cc900-leaf-none`                                                               |
| `regkw.c`    | does `register` change which value V4.23 homes in IZ / QIZ across calls (no: only declaration order moves them, `k_reg_ba`); the `__doprnt` shape                                                                                                                                     | `2026-11-09-35-micro-regkw`           | none (read directly)                                                                                |
| `homes2a.c`  | which value lives in IZ / QIZ / XIZ / a slot across calls: generated (two-local factorial, random events, parameters, longs, inner blocks, loops); every variable is read through its own sink call so its home can be read off the listing                                           | `2026-11-09-37-micro-homes2a`         | `sessions/2026-11-09_cc900-homes2` (fit file)                                                       |
| `fpp5.c`     | E2: one or two operation slots among up to 12 call slots (generated by the session's `gen_fpp5.py`): the constant 3 does not grow, the call arguments do not matter                                                                                                                   | `2026-11-09-36-micro-fpe2c`           | `sessions/2026-11-09_cc900-fp-e2b`                                                                  |
| `fpp6.c`     | E2: what the constant 3 counts: statements that need no slot (`gi = 1`, copies, void calls, O statements) inserted around `fd(gd * gd2)` (`gen_fpp6.py`)                                                                                                                              | `2026-11-09-38-micro-fpe2d`           | `sessions/2026-11-09_cc900-fp-e2b`                                                                  |
| `fpp7.c`     | E2 unit meter: `T0; 8 calls; X` for 32 statement kinds X (the two slots of T0 read off X's units), and wraps (`gen_fpp7.py`)                                                                                                                                                          | `2026-11-09-39-micro-fpe2e`           | `sessions/2026-11-09_cc900-fp-e2b`                                                                  |
| `fpp8.c`     | E2 unit meter for the library's constructs (returns, nested calls, logical and / or, FP-condition loops, conversions); third and fourth operation slots (`gen_fpp8.py`)                                                                                                               | `2026-11-09-40-micro-fpe2f`           | `sessions/2026-11-09_cc900-fp-e2b`                                                                  |
| `fpp9.c`     | held-out check of the window rule (seeded random functions; predictions recorded before the run, `gen_fpp9.py`)                                                                                                                                                                       | `2026-11-09-41-micro-fpe2g`           | `sessions/2026-11-09_cc900-fp-e2b`                                                                  |
| `homes2b.c`  | held-out check of the homes2 rule (predictions recorded before the run): new random functions of the same families and ten loop shapes, sink-read                                                                                                                                     | `2026-11-09-42-micro-homes2b`         | `sessions/2026-11-09_cc900-homes2` (held out)                                                       |
| `fpp10.c`    | E3 (slot count and sharing), round 1: which statements remove the second half of the temporary region (an int global-to-global copy), _sqrt-like int locals, which operand slot an operation on two temporaries writes, slots freed inside a statement, loop bodies, reserved slots   | `2026-11-10-2-micro-fpe3a`            | `sessions/2026-11-10_cc900-fp-e3`                                                                   |
| `fpp11.c`    | E3 round 2: the region size as a counter kept across two passes (several resetting copies with FP code between), which statements reset it (indexed / member / pointer copies, increments, chains, casts), the _sqrt / _fmod / _pow shapes, the long shadow, _log clones              | `2026-11-10-NN-micro-fpe3b` (pending) | `sessions/2026-11-10_cc900-fp-e3`                                                                   |
| `chidx.c`    | the element address or pointer sum whose index is a char: a signed char stays a byte (`add A,(c)` / `(XBC+A)`, zero-extended whole on a char array), an unsigned one is widened to WA first; by base kind, element size, read / store / sum                                           | `2026-11-10-4-micro-chidx`            | none (read directly; the forms are `model/chidx.py`'s docstring)                                    |
| `evorder.c`  | the order in which V4.23 evaluates the two operands of - ^ * by operand kind (13 x 13 kinds, `gen_evorder.py`, the left side reads g* and the right h* globals): a right operand that needs code goes first (value into WA, or BC when the left needs WA; its address into XWA or (XBC+WA)), an addressed left goes first; the same at the four option sets (run 2026-11-10-9-micro-evorder; -8 is the same-symbol draft) |
| `evorder_st.c` | the same int kinds as a value stored into a global (`es_*`: the accumulator is WA, the source takes BC) and as a pushed argument (`ea_*`: the source takes WA, the accumulator the first free family), for - and ^ (`gen_evorder2.py`, run 2026-11-10-10-micro-evorder2) |
| `evorder_l.c` | the kinds as longs, returned (`el_*`: the same rule in XHL / XWA; `!l` and `-l` go through XWA), for - and ^ (`gen_evorder2.py`, run 2026-11-10-10-micro-evorder2) |
| `evorder_d.c` | the int kinds for / and % (`ed_*`): the same order rule with the accumulator in WA (`exts XWA / divs XWA,src / ld HL,WA`, the remainder from QWA; -O with a plain left: `divs XHL`), the source in BC (`gen_evorder3.py`, run 2026-11-10-11-micro-evorder3) |

    python3 -I -B model/score.py ~/compartilhado/cc900-oracle/runs/2026-11-09-18-micro-fpprepass/out/v423/O3XS/micro corpus/probes/fpp1.c --opt O3XS
