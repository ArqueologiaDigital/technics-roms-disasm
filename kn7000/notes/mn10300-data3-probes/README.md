# Probes of lane mn10300-data3 (wave 11, 2026-11-06)

Notes: `../mn10300-data3/README.md`.  The generator-wide measurements reuse the earlier lanes' probes
(`../mn10300-data-probes/data_stats.py`, `../mn10300-data-probes/opaque_left.py`,
`../mn10300-data2-probes/opaque_rows.py`, `../mn10300-formats-probes/field_names_census.py`); the scripts
here answer this lane's own questions.

| script                  | question it answers                                                                                                                                                                                                            | run (from the repository root)                                    |
|-------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|-------------------------------------------------------------------|
| `panel_ctrl_slider.py`  | N-4b34dd8b: which latched panel control PanelCtrlValueGet(0xC2) (KN6000 0xC6) answers -- the index, the value pointer, the TYPE-2 dispatch handler of that index and whether the handler stores to that pointer; exit 1 if not | `python3 kn7000/notes/mn10300-data3-probes/panel_ctrl_slider.py`  |
| `frozen_names_check.py` | N-fb88572c: does every tree's `gui_object_names.tsv` name each object with an empty ResName exactly as the data source labels it (labels.sym), with no name twice; exit 1 if not                                               | `python3 kn7000/notes/mn10300-data3-probes/frozen_names_check.py` |

`panel_ctrl_slider.py` reads the reference images (`kn7000/baserom/kn7000_program.rom`, `kn6000/baserom/
kn6000_program.rom`, regenerated by the Makefiles) and the committed `labels.sym` / code.  Its expected
output (2026-11-06):

    941: control 0xC2 -> index 26 (wire 0xD2); value pointer 0x5006BEAD; dispatch handler PanelCtrlLatch32 0x484AD772; handler stores to the pointer: yes
    kn6000: control 0xC6 -> index 30 (wire 0xD6); value pointer 0x50022787; dispatch handler func_4C047993 0x4C047993; handler stores to the pointer: yes

The service-manual evidence (which slider the panel CPU's AD2 / AD6 reads) is read off the schematics with
`pdftotext -layout`: the KN7000 one (`~/compartilhado/KN7000/service_manual/technics_sx-kn7000_keyboard.pdf`,
the CPL board: `VR1102` "APC/ SEQUENCER" -> R1105 -> pin 13 AD2) and the SX-KN6500 one
(`~/compartilhado/KN6000/service_manual_kn6500.pdf`, SCHEMATIC DIAGRAM-30: `VR1` 20K "APC SEQUENCER VOLUME" ->
R13 -> pin 17 AD6; parts list `VR1 EVD07205B24G VR,APC SEQUENCER VOLUME CPL`).  The manuals are not in the
repository (they are not ours to publish); the page and part references are.
