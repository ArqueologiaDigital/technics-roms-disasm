# KN7000 disassembly

A byte-exact disassembly project for the **Technics SX-KN7000** firmware.

The keyboard's main CPU is a **Panasonic MN10300/AM33** (it embeds the kernel
banner `MILK MN10300 Ver1.0R1`) — *not* the Toshiba TLCS-900 used by the KN5000.
The two flash images reverse-engineered here are produced by the sibling
[`kn7000_extraction`](../kn7000_extraction) repo from the original system-update
floppy disks:

* `kn7000_program.rom` — 0x3F6F01 bytes, main firmware, mapped at CPU `0x48400000`
* `kn7000_table.rom` — 0x3E94D4 bytes, resource archive, mapped at CPU `0x48000000`

## Goal: 100% byte-match

`make verify` reassembles the source in `src/` and checks that the result is
**byte-for-byte identical** to the original images:

```
$ make verify
OK    kn7000_program.rom is 100% byte-identical to the original
OK    kn7000_table.rom is 100% byte-identical to the original

All images reproduced byte-for-byte.
```

The project is already at 100% match — because it *starts* as a skeleton in
which every byte is pulled in verbatim (`.incbin_range`). Reverse engineering
then proceeds by replacing those raw ranges, region by region, with real
disassembled instructions and typed data — while `make verify` guarantees the
rebuilt image never drifts from the original. "Understood" bytes go up; the
byte-match invariant is held at 100% the whole way.

## Layout

```
src/program.s   MN10300 firmware image. Boot header is hand-disassembled;
                the rest is raw .incbin_range awaiting disassembly.
src/table.s     Resource archive: 85-entry offset directory + 84 asset segments.
tools/kn7asm.py Self-contained assembler/linker (see "Toolchain" below).
tools/dump_table_dir.py   Annotates the table directory.
disasm/         Reference disassembly listings (see below).
baserom/        Reference images, regenerated by make (git-ignored).
build/          Reassembled output (git-ignored).
```

## Building

```
make            # build + verify (regenerates baserom/ from the disks if needed)
make verify     # assert 100% byte-match
make disasm     # (re)generate the full disassembly listings via MAME unidasm
make clean      # remove build/
make distclean  # also remove regenerated baserom/ and listings
```

`make` regenerates the reference images by invoking the sibling extraction repo,
so the whole chain — original `.SLD` floppies → LZSS decompress → reassemble →
byte-compare — is reproducible from scratch. Override paths if your checkout
differs:

```
make EXTRACT_DIR=/path/to/kn7000_extraction DISKS_DIR=/path/to/KN7000 \
     UNIDASM=/path/to/mame/unidasm
```

## Toolchain

There is no free GNU binutils target for the MN10300 in common distros, so this
project ships its own minimal assembler, [`tools/kn7asm.py`](tools/kn7asm.py)
(pure Python, no dependencies). Its job is reconstruction, not full codegen: it
understands `.byte`/`.word`/`.long`/`.space`, labels/`.equ`/`.org`, and the two
`.incbin` forms. `.incbin_range "file", START, END` asserts that the current
output offset equals `START`, so any gap or overlap in the region layout is
caught immediately.

Disassembly listings are produced by **MAME's `unidasm`**
(`unidasm <rom> -arch mn10300 -basepc <cpu_addr>`); `make disasm` drives it.
`disasm/program_entry.asm` (the boot/entry region) and
`disasm/table_directory.asm` are committed as curated samples; the full ~30 MB
linear listing is regenerable and git-ignored.

## Status

Skeleton stage: 100% byte-match achieved, boot header (0x0–0x80) hand-annotated,
everything else still raw. See [`kn7000_extraction/NOTES.md`](../kn7000_extraction/NOTES.md)
for the memory map, region map and other findings that will guide the work.
